A few rules of thumb I keep coming back to:

- **Name tools for the task, not the API.** `summarise_open_cases` beats `query_case_object`.
- **Keep inputs small and typed.** Every optional parameter is a chance for the model to guess.
- **Write the description for the model.** Say when to use the tool and when *not* to.
- **Return less.** Trim payloads to what the next step needs.
